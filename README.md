# 模拟社团老大 · 雾港风云

一款架空港口城市背景的本地生涯策略游戏。玩家接过父亲沈振海留下的“和联胜”，从一条老街起步，招募头目、经营地盘、决定血拼战术、收编敌将，最终统一雾港。

## 已实现

- 60个月主战役，每月3个行动点；发起血拼额外消耗1个行动点
- 人手分能战／整补／养伤三态：出战即离池，整补约2个月归队，养伤4~5个月且要付药钱
- 人手上限绑定地盘数——想养更多人，只能先拿地
- 8块城区、3家敌对社团与中央港区终局
- 敌方会主动扩张：三家互相吞并，抢到中央港区的一家将与所有人接壤
- 新打下的地盘有3个月驻防期：收入减半、易被反夺，可派头目坐镇提前结束
- 招募市场：固定剧情角色＋可重玩的普通人才
- 头目五维：武力、统御、谋略、经营、魅力
- 血拼前选地盘、三名头目、参战人手与战术
- 开局、僵持、决胜三段战报，包含伤亡、受伤与俘虏收编
- 地盘经营、驻防、每月收支和敌对势力反攻
- 14名核心人物，角色忠诚、怨气、功劳与伤势持续记录
- 父亲旧账、旧部要位、敌将投降、功高震主等剧情链
- 义、威、利三种执掌倾向与多结局评价
- 本地自动存档，无后端、无CDN、无数据上传

## 可玩性扩展（2026-08）

- **战术克制环**：每块敌方地盘有防守姿态（铁壁死守／外线游斗／重赏死士／人心浮动），查明情报才可见；四种战术各有克制与被克，稳扎稳打对所有姿态中立。蒙着打时战前评估不含姿态修正——情报从加分项变成选战术的依据
- **外部压力有牙齿**：压力顶到75触发警队大扫荡；民心太低触发码头罢工；港城联盟成形后每6个月上门收“公摊”
- **外交层**：递茶讲数（花钱换4个月停战）、挑拨离间（把一家的刀口引向同行）、安插内应（削驻防＋查敌情）
- **头目主政**：可委任头目坐镇地盘，按经营／统御／魅力／谋略持续抬收入、厚驻防、安街面、压风声，但主政期间不能出战
- **事件池扩容与事件链**：走私船、记者调查、父亲旧友、阿七独当一面等选择会在数月后回响
- **章节转折**：第12／24／36／48月各有一次全局抉择，给60个月一个“幕”的结构
- **每局随机世道**：开局抽2条世界规则（阴雨连绵／海关大检查／金价飞涨／老兵还乡／严打之年／走私旺季），可在开局界面换年景
- **流派拉大**：义＝劝降收编流（伤员好得快、收编忠诚高），威＝速攻震慑流（胜仗削邻地驻防），利＝经济流（收入高、讲数和招人便宜）

## 启动

在本目录执行：

```bash
python3 -m http.server 8777
```

然后访问 `http://127.0.0.1:8777/`。

## 检查与封装

```bash
node --check app.js
node tests/structure.test.mjs
node tests/balance.test.mjs
python3 build_single.py
```

`balance.test.mjs` 用固定种子的三种玩家画像（莽夫／稳健／躺平）各跑 24 局完整战役，锁住难度曲线。
当前基准：稳健打法标准难度约 42 个月通关，莽夫速通约 18 个月，死战难度通关率约五成，躺平必亡。
注意：敌方地盘的开局防守姿态是固定的（易主后才随机重掷），否则固定种子会失去意义。
改动战斗或经济数值后它会先叫。

打包后会生成额外的 `模拟社团老大-单文件版.html`，不覆盖模块化源码。

本作品是架空剧情策略游戏，不对应现实组织、人物或城市。
